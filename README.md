# 단속카메라 경보 (오프라인)

공공데이터포털의 **전국무인교통단속카메라표준데이터**(CSV)를 폰에 저장해 두고, 인터넷 없이 GPS만으로 단속카메라 접근을 음성으로 알려주는 웹앱입니다.

- 설치 주소: https://nodriver79s-cmd.github.io/camera-alert/
- 처음 한 번 와이파이에서 열고 크롬 ⋮ → **홈 화면에 추가** → 이후 인터넷 없이 사용
- 카메라 데이터는 앱 안의 "카메라 데이터 불러오기"로 CSV를 선택 (폰에만 저장, 서버로 전송 없음)
- 화면이 켜져 있을 때만 작동하며, 이동식 카메라는 공공데이터에 없어 안내되지 않습니다. 도로 표지판을 우선하세요.

데이터 출처: 공공데이터포털(data.go.kr) 전국무인교통단속카메라표준데이터
