가까운 카메라 (방향 무관)
  • —위치를 찾으면 표시돼요
설정
시속 90km 이상이면 1차 경보 거리를 자동으로 최소 800m로 늘려요.
사용 방법
  1. PC에서 공공데이터포털(data.go.kr)의 전국무인교통단속카메라표준데이터를 CSV로 내려받아요. (다운로드는 PC에서만 돼요)
  2. 파일을 폰으로 옮긴 뒤 카메라 데이터 불러오기로 선택해요. 한 번 불러오면 폰에 저장돼서 다음부터는 필요 없어요.
  3. 인터넷이 없어도 시작을 누르면 GPS로 경보가 울려요. 처음 위치를 잡을 땐 트인 곳에서 1~몇 분 걸릴 수 있어요.
  4. 가장 좋은 열기 방법: 이 앱 폴더를 웹 주소(예: GitHub Pages)에 올려 크롬으로 한 번 연 뒤 메뉴 → 홈 화면에 추가. 그다음부터는 인터넷 없이 앱처럼 열려요. 파일을 폰에서 바로 열면 브라우저에 따라 위치가 막히거나 데이터가 저장되지 않을 수 있어요.
  5. 집에서는 모의 주행으로 경보 소리를 미리 확인할 수 있어요.
  6. 한두 달에 한 번 최신 파일로 다시 불러오면 새 카메라가 반영돼요.

주의: 이 페이지는 화면이 켜져 있고 브라우저가 앞에 떠 있을 때만 작동해요(시작하면 화면 꺼짐을 막아요). 이동식 카메라는 공공데이터에 없어서 안내되지 않아요. 데이터가 실제와 다를 수 있으니 도로 표지판을 우선하세요. 단속구분 코드는 1=과속, 2=신호·과속, 3=신호, 4=주정차로 해석했어요.
