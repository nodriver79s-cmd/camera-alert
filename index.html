시작 설정
브라우저 규칙 때문에 소리는 화면을 한 번 눌러야 켜져요. 자동 시작 후 아래에 나오는 파란 안내를 한 번 눌러 주세요.
음성 설정
경보 설정
시속 90km 이상이면 1차 안내를 자동으로 800m 앞에서 해요.
사용 방법 · 데이터 관리
  1. PC에서 공공데이터포털(data.go.kr)의 전국무인교통단속카메라표준데이터를 CSV로 내려받아 폰으로 옮겨요.
  2. 위의 데이터 불러오기로 CSV를 골라요. 폰에 저장돼서 다음부터는 필요 없어요.
  3. 와이파이에서 이 주소를 한 번 열고 크롬 ⋮ → 홈 화면에 추가. 그다음부터는 인터넷 없이 열려요.
  4. 앱을 켜면 자동으로 시작돼요. 처음 위치를 잡을 땐 트인 곳에서 1~몇 분 걸릴 수 있어요.
  5. 한두 달에 한 번 새 CSV로 다시 불러오면 새 카메라가 반영돼요.

화면이 켜져 있을 때만 작동해요(시작하면 화면 꺼짐을 막아요). 이동식 카메라는 공공데이터에 없어 안내되지 않아요. 도로 표지판을 우선하세요. 단속구분 코드는 1=과속, 2=신호·과속, 3=신호, 4=주정차로 해석했어요.
